# Центр карьеры · Южный университет (ИУБиП)

Одностраничное веб-приложение карьерного хаба: вакансии, запись на консультацию, геймификация прогресса и дашборд трудоустройства.

🌐 **Сайт:** https://eagle1man.github.io/iuubip-career-hub/

## Запуск

Откройте `index.html` двойным кликом — всё работает офлайн, без зависимостей.

## Что внутри

- Вакансии: поиск + фильтр по направлениям, 8 карточек, toast-уведомления
- Запись на консультацию: вечерние окна для заочников, даты на 7 дней вперёд
- Мой прогресс: прогресс-бар и 6 бейджей
- Дашборд: трудоустройство, зарплаты, график по направлениям
- Адаптив: мобильная вёрстка, табы со скроллом

## Технологии

HTML + CSS + JS в одном файле. Без фреймворков и CDN.
